# SafePay Web Demo

A polished, Vercel-ready Next.js website that presents SafePay as a launch-ready fintech product.

## What this project includes

- Marketing homepage for presentations
- Interactive browser-based product demo built as a web experience
- Premium dark fintech UI inspired by the provided screen sequence
- Step-by-step flow:
  - Splash
  - Onboarding 1–3
  - Sign Up
  - Login
  - OTP Verification
  - Dashboard
  - Add Card
  - Manage Cards
  - Pair Device
  - Device Details
  - Wearable Control
  - Payment Success
  - Activity
  - Receipt
  - Notifications
  - Security Center
  - Settings
  - Help
  - Profile
- Reusable component system
- No external image dependency
- Works well for GitHub + Vercel deployment

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`

## Deploy to Vercel

This project is a web app, so it can be deployed directly to Vercel.

- Framework Preset: `Next.js`
- Build Command: leave default
- Output Directory: leave empty
- Install Command: leave default
